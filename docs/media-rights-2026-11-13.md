## Images and code

For images, prefer team-created diagrams/renders or individual NASA assets with checked credit/rights notices. [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) generally permits factual educational use with acknowledgement; third-party items, identities and identifiable people require separate consideration. Do not treat every NASA-hosted image or music track as unrestricted, imply endorsement, or label generated art as measured lunar evidence.

[ESA's copyright notice](https://www.esa.int/articles/about-us/who-we-are/governance/law/esa-copyright-notice) permits educational/informational image reuse with the specified credit; commercial promotion requires approval. Prefer items expressly labelled [CC BY-SA 3.0 IGO](https://www.esa.int/articles/about-us/directorates/resources-and-services/creative-commons-attribution-sharealike-3-0-igo-cc-by-sa-3-0-igo-licence), preserving attribution/licence, modification notices and share-alike for adaptations. This licence does not automatically cover every ESA item or third-party/personality rights.

[JAXA's site policy](https://global.jaxa.jp/policy.html) and [Digital Archives guide](https://jda.jaxa.jp/service.php?lang=e) have more restrictive use/modification conditions; the [current Japanese guide](https://jda.jaxa.jp/service.php) expressly requires applications for personal SNS/website posting. Do not assume that a public hackathon website is an exempt educational use. NASA first and expressly licensed ESA items second are recommendations; no particular image has been cleared in this review.

For code, keep using the bounded, pinned candidates in DATA_PREPARATION §3 and inspect the actual files, dependency licences, notices and modifications. [GitHub's licensing guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains that a public repository without a licence is not general permission to reproduce/distribute/modify it. MIT/Apache/BSD labels do not automatically cover bundled images, music, model weights, data or fonts. Do not relicense a third-party asset under the product's code licence.
